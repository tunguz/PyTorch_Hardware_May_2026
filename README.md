# State of PyTorch Hardware Acceleration: May 2026

A comparative technical analysis of the PyTorch hardware acceleration landscape as
of May 15, 2026, covering NVIDIA CUDA, AMD ROCm, Google TPU/XLA, and Apple
Silicon MPS.

Version: 0.2
